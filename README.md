# Roblox Macro Tool

A small Windows helper that automates repetitive clicks and key presses while you play Roblox — record a sequence once, replay it on demand.

## Download

Latest build: **[RobloxMacro.zip](../../releases/latest/download/RobloxMacro.zip)**

Unpack the archive and run the installer inside.

## Requirements

- Windows 10 / 11 (64-bit)
